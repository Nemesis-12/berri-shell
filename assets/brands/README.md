# Brand marks

`claude.svg` and `codex.svg` are from the [LobeHub icon set](https://github.com/lobehub/lobe-icons)
(MIT license), used only as source path data for the Agents cell's ring
centers. They are drawn filled in the theme's text color (not brand colors)
by `BrandMark.qml`, which reads normalized path data from `BrandPaths.js`
(generated once from these files; see the header comment there).
